## Как добавить тему

1. Добавьте скриншот в `assets/preview/`.
2. Создайте новый раздел в `## Темы`.
3. Укажите автора, ссылку на оригинал и тип темы.
4. Добавьте способ установки, если он отличается.

## Лицензия

Темы принадлежат их авторам. Перед использованием проверьте лицензию в репозитории или на странице оригинала.
